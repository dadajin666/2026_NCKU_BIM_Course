# 2026-10-30 A、C 整合與前端實測

測試版本：`fa3b3ad`，已包含 main 的 C 規則更新（PR #4）。輸入為 10/27 外掛實際匯出的 NCKU／Level 1／New Construction 快照。使用類組、防火構造、法定樓層數等尚未由使用者確認，測試起始設定維持 null。

## 測試方式

現有 `src/page.html` 沒有 JSON 匯入功能，因此在本機驗證資料夾使用相同模板、geometry.js、rules.js、review.js 與規則包，產生注入真實快照的獨立測試頁。未修改 D 的頁面原始碼、共用 build.js 或既有 generated HTML。

頁面頂端有測試橫幅，說明來源為真實 Level 1，並揭露既有前端仍有固定 3F 標籤。此頁是測試預覽，未發布至網際網路。localhost 服務僅綁定 127.0.0.1。

- 上述操作未出現瀏覽器 console error。

## 尚待 D 處理的畫面問題

1. 缺少模型快照匯入入口，現有正式 build 固定使用範例資料。
2. 房間區標題、卡片、平面及圖框文字仍固定 3F，與 Level 1 真實模型不符。
3. SVG viewBox 固定為 `-24 -40 700 330`。真實房間繪圖 X 約 -137 至 -82，落在可見範圍外，圖面看不到房間。應依模型範圍取景；現有房間還使用包圍矩形呈現，沒有忠實繪製多邊形外框。
4. 未填樓層數時，readSettings 的 Number(空字串) 會轉成 0；未操作的初始頁還會出現設定已變更提示。未知值應維持 null，不能把 0 當成已確認樓層。
5. 未顯示 unresolved_stairs，亦未使用 footprint_loops 逐圈繪製樓梯分件。
6. 批次與覆核目前保存在頁面記憶體中，重新整理會重置；尚未接持久化儲存。

這些結果驗證的是整合與缺資料處理，不代表逃生距離、完整路網或法規結論已完成驗收。房門關聯、走廊中心線、淨寬及樓梯終點等模型資料仍待補齊。
